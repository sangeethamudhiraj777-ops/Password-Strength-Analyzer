# Password Strength Analyzer

## Overview

A Python-based Password Strength Analyzer that evaluates password security based on password length, uppercase letters, lowercase letters, numbers, and special characters.

## Features

* Password length validation
* Uppercase letter detection
* Lowercase letter detection
* Number detection
* Special character detection
* Password strength rating (Weak, Moderate, Strong)
* Password improvement suggestions

## Technologies Used

* Python 3

## How to Run

1. Open the project folder.
2. Open Terminal or PowerShell.
3. Run:

py password_analyzer.py

4. Enter a password when prompted.

## Example

Input:
Hello@123

Output:
Password Score: 5
Password Strength: Strong
